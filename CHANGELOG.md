# Changelog

All dates use Asia/Seoul.

## 1.0.0 — 2026-11-04

### Added
- Python FastAPI sizing backend, validated Pydantic inputs and OpenAPI.
- Deterministic sizing engine, measurement weighting, fit preference and alternatives.
- Request-supplied custom size charts and fictional demo garment catalog.
- Responsive customer website, animated visual design and cm/in switching.
- API tests, Dockerfile, project metadata and security headers.
- Public production Vercel deployment.
- Animated professional README, architecture documentation, skills and project memory.

### Fixed
- Conditional static-assets mount when Vercel CDN promotion removes physical assets from the function bundle.

### Pending
- Vercel GitHub integration repository access, verified merchant charts, fit outcome validation, commercial security review and production monitoring.

## 1.1.0 — 2026-11-04

### Added
- Photographic fashion homepage replacing the original cartoon model.
- Guided front and side photo input with consent-gated MediaPipe pose segmentation on-device.
- New quality-checked Python photo geometry API with low-confidence circumference estimates.
- Natural-language parsing of explicitly labelled and unit-specified measurements.
- WebCrypto AES-GCM browser-local encrypted user profile with unlock, update, delete, export and import.
- Photo geometry regression tests and privacy/accuracy limitations guide.

### Verified
- GitHub Actions CI #5 succeeded, including syntax and API tests.
- Public browser test passed photographic homepage, prompt parser, sample fit result, encrypted local profile creation, locking/unlocking, restored values.
- No evidence yet of calibrated accuracy for image-derived measurements.

### Open
- Authenticated cross-device profiles require a separate cloud database and identity provider.
- Retailer size charts and photo-derived precision need evidence and independent validation.


## 1.2.0 — 2026-11-04

### Added
- Three selectable example shopper journeys (tops, denim and dresses) with representative real-fashion photography and explicit fictional measurement datasets.
- Four-step animated live website walkthrough: photo guidance, editable measurements, encrypted local-profile preview and a real POST request to the Python recommendation API.
- Controls for step navigation, automatic playback, editing values, retrying API results and transferring the chosen example to the full fitting studio.
- Actual on-device MediaPipe landmark and approximate torso-guide overlay on user-supplied image previews after a successful scan, distinct from the synthetic examples.
- README photographic scenario gallery, animated demo workflow and dedicated demo engineering/QA guide.
- Automated Python contract tests covering all three sample products and demo asset wiring.

### Clarifications
- Editorial example photos are not the source of the sample numbers.
- The sample profile preview never persists data; only the separate encrypted profile vault can do that with customer consent.
- Photo-derived real-world body measurement accuracy remains unvalidated.
